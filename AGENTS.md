# AI-Avatar — подсказки для агентов

## Поиск по этому коду: сначала GBrain, потом grep

Этот проект проиндексирован в GBrain как источник `ai-avatar`
(федеративный — находится и без указания источника).

Смысловой вопрос — «где логика темы», «как устроена навигация», «где
обрабатывается состояние» — ищется так:

```bash
gbrain search "theme colors"
```

Запрос формулировать на языке кода (английском): индекс построен по исходникам.
Ответ приходит с путём, диапазоном строк и оценкой релевантности — то есть
сразу видно, куда смотреть.

`grep`/`rg` остаются лучше для точной строки, имени файла или литерала.

Символьные команды (`code-def`, `code-refs`, `code-callers`, `code-callees`) на
этом проекте **не работают**: индексатор не разбирает символы Dart (проверено
2026-08-06 — возвращает 0). Здесь только `gbrain search` + `grep`.

## После существенных правок кода

Индекс сам не обновляется:

```bash
gbrain sync --source ai-avatar --strategy code
```

## Запись в общую память

Контракт — `~/.claude/skills/gbrain-learn/SKILL.md`. Коротко: ошибку или вывод
писать страницей с YAML-frontmatter (`type`, `date`), явными `[[связями]]`,
полем **Кто** (`claude` | `codex`) и проверяемым утверждением. Повтор ошибки —
`timeline-add` к существующему инциденту, а не новая страница.
